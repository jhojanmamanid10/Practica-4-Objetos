## Getting Started

Welcome to the VS Code Java world. Here is a guideline to help you get started to write Java code in Visual Studio Code.

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies

Meanwhile, the compiled output files will be generated in the `bin` folder by default.

> If you want to customize the folder structure, open `.vscode/settings.json` and update the related settings there.

## Dependency Management

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).


Cuestionario

1. ¿Qué diferencia existe entre una clase y un objeto?
Una clase es un modelo o plantilla que define atributos y métodos. Un objeto es una instancia de esa clase, es decir, una representación concreta creada a partir de ella.

2. ¿Qué función cumplen los atributos?
Los atributos almacenan las características o datos que describen el estado de un objeto.

3. ¿Qué función cumplen los métodos?
Los métodos representan las acciones o comportamientos que puede realizar un objeto.

4. ¿Qué ventaja proporciona un constructor?
El constructor permite inicializar un objeto automáticamente cuando se crea, asignando valores iniciales a sus atributos.

5. ¿Qué significa encapsular una clase?
Significa proteger los datos internos de una clase y controlar el acceso a ellos mediante métodos, como getters y setters.

6. ¿Cuál es la diferencia entre public y private?
public permite acceder a un atributo o método desde otras clases. private restringe el acceso directamente a la clase donde está declarado.

7. ¿Para qué sirven los getters y setters?
Los getters permiten obtener el valor de un atributo y los setters permiten modificarlo de manera controlada.

8. ¿Qué problema resuelve List?
List permite trabajar con una colección ordenada de elementos, facilitando almacenar, recorrer, agregar y eliminar objetos.

9. ¿Qué diferencia existe entre List y ArrayList?
List es una interfaz que define operaciones para trabajar con listas. ArrayList es una implementación concreta de esa interfaz.

10. ¿Qué diferencia conceptual existe entre agregación y composición?
La agregación representa una relación donde un objeto puede existir independientemente del otro. En la composición, el objeto contenido depende del objeto principal para existir.

11. ¿Qué significa que una clase herede de otra?
Significa que una clase hija puede utilizar los atributos y métodos de una clase padre, además de agregar sus propias características.

12. ¿Qué función cumple extends?
extends se utiliza para indicar que una clase hereda de otra clase.

13. ¿Qué función cumple super()?
super() llama al constructor de la clase padre para inicializar la parte heredada del objeto.

14. ¿Por qué la herencia permite reutilizar código?

Porque una clase hija puede utilizar los atributos y métodos que ya fueron definidos en la clase padre, evitando escribir nuevamente el mismo código.
